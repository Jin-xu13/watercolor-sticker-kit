# 水彩画法规格

## 一、三层明度，不许一次涂满

每枚贴纸都按这三层搭，缺一层就会变成平涂：

| 层 | 浓度 | 覆盖范围 | 作用 |
|---|---|---|---|
| 第 1 层·铺底 | 8%–15% | 稍微**溢出**形体轮廓，边缘不齐 | 定住外形，留下水痕 |
| 第 2 层·中间调 | 30%–45% | 停在形体内侧，**避开高光** | 给体积 |
| 第 3 层·暗点 | 55%–70% | 只占主体面积 5%–10%，一处到两处 | 压住重心 |

第 3 层最容易做过头。宁可只点一处。

## 二、水彩特征（这些是「像水彩」的关键）

- **颜料沉积边**：每一层 wash 干后的边缘比中间深一档，边缘要能看见一条细的深色线
- **纸白高光**：靠留白，不靠白色颜料。高光面积占主体 10%–25%
- **外溢**：第 1 层可以略微溢出最终轮廓 1%–2%，形成不整齐的水痕
- **水痕／开花**：允许 1–2 处极淡的水痕圆斑，不要满天星
- **纸纹**：冷压水彩纸的粗细颗粒，只在贴纸范围内部可见

## 三、颜色

- 从源照片取 3–5 个颜色，**整体降饱和约 20%**
- 最深的明度值用 `#2F3742`（深蓝灰）或 `#4A4038`（暖褐灰），**禁止纯黑 `#000000`**
- 允许 1 个点缀色，用源照片里本来就有的一处暖色（尾灯红、罐体红条、招牌暖黄）
- 同一套贴纸共用同一色板，第 2 枚起以样张为准，不要每枚重新调色

## 四、手剪白边

这一层决定「像不像贴纸」。

| 参数 | 值 |
|---|---|
| 颜色 | `#F7F2E8` |
| 厚度 | 贴纸短边的 4%–6%，**沿轮廓会有 ±15% 的宽窄变化** |
| 转角 | 圆角，半径约白边宽度的 1.2 倍 |
| 外缘 | 轻微不规则，像剪刀走过，不要完美的等距 offset |
| 内缘 | 白边与画面的交界要干净，但允许极细的毛边 |

**反例**：一圈宽度完全一致的白色描边 → 那是图标，不是贴纸。

## 五、投影

- 扁平投影，只在贴纸轮廓下方
- 向下偏移约贴纸高度的 2%–3%
- 模糊半径约白边宽度的 0.8 倍
- 不透明度 10%–14%，颜色用 `#000000` 混合 8%
- **不许落在虚构的地面上**，贴纸是浮空的

## 六、透明（两段式，不能一步到位）

**图像模型不做真透明。** 给它 `background: transparent` 参数，返回的仍是 opaque RGB（color type 2），没有 alpha 通道。所以透明是两步做的：

**第一步·生成端**：要求纯白底 `#FFFFFF`，平涂、无渐变、无纸张背景、无地面阴影。检验办法很简单——看画布四角是不是一片死白。

**第二步·抠图端**：跑 `scripts/matte.py`。它是从画布四边向内的**连通洪水填充**，只清除与边缘连通的白，所以：

| 区域 | 处理 |
|---|---|
| 画布白底 | 清除，alpha=0 |
| 贴纸的暖白留边 `#F7F2E8` | **保留**（通道极差 15 > 阈值 10） |
| 浮动投影（明度约 224） | **保留**（低于 238 阈值） |
| 贴纸内部的白高光 | 保留（不与边缘连通） |

**为什么不用全局「去白」**：那会把贴纸内部的纸白高光和暖白留边一起吃掉，贴纸会变成一张烂网。

**交付前必须抽查**：PNG 头的 color type 应为 6。也可以把同一张图再抠一次，清除比例接近 0 才算干净——如果还有明显比例，说明有白色孤岛没连通到边缘，需要手工补。

**不许**用「接近白色的浅灰」冒充透明，也不许给贴纸垫一块方形底板。

## 七、尺寸分级

| 级别 | 主体在画布上的占比 | 用途 |
|---|---|---|
| 主体贴纸 | 80%–85% | 一套里 1–2 枚，挑轮廓最干净、最有辨识度的 |
| 配件贴纸 | 55%–70% | 其余，做补充和呼吸 |

四周始终保留 12% 透明安全边，免得贴纸边缘被裁到。
